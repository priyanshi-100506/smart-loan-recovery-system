🚀 Smart AI-Powered Loan Recovery System
End-to-End ML Pipeline | Risk Scoring | Recovery Prioritization | Business Insights

This project builds a fully intelligent loan-recovery engine that analyzes borrower behavior, predicts default probability, assigns recovery priority, and generates business-ready insights—all powered by Machine Learning.

📌 Key Features
🔹 1. Default Risk Prediction (ML Model)

Processes loan attributes (income, DTI, interest rate, payment ratio, etc.)

Trains a classification model to estimate default probability

Outputs default_risk_prob for every borrower

🔹 2. AI-Generated Recovery Scoring

A scoring engine converts ML predictions + financial indicators into a Recovery Score (0–100) that determines:

High Priority (fast-recoverable, high-value cases)

Medium Priority

Low Priority (lower recovery likelihood)

🔹 3. Portfolio Health Insights

Automatically generates business insights on:

Portfolio stability

Risk clusters

Borrower behavior patterns

Income–payment dynamics

High-risk borrower segments

🔹 4. Visual Analytics (LinkedIn-Ready Charts)

Includes clean, publication-ready charts:

Default risk distribution

Payment to income vs. default probability

Regression relationship visualizations

SHAP model explainability

Priority-wise recovery distribution

🧠 Tech Stack

Python

Pandas, NumPy

Scikit-Learn

XGBoost / RandomForest

Matplotlib

(Optional) SHAP for Explainability

Works smoothly on Google Colab / Kaggle
